# 📝 Pink Pastel To-Do List Application

A lightweight, responsive single-page task management web application built with HTML5, Bootstrap 5, and vanilla JavaScript. Features local storage persistence, client-side input validation, real-time search filtering, and a pastel pink aesthetic.

# ✨ Features

Full Task Management (CRUD):

Create: Add tasks with title, description, and optional deadline.

Read: Display active and completed tasks cleanly in a list layout.

Update: Edit task details or mark tasks as completed (strikethrough state).

Delete: Remove individual tasks.

Form Validation:

Task Title: Enforces 5 to 25 characters.

Task Description: Enforces 20 to 100 characters.

Search & Filter: Search across titles, descriptions, or deadlines with a single-click reset to show all items.

Persistent Data: Uses localStorage to save state locally in the user's browser across page refreshes.

Real-Time Clock: Displays a dynamic live clock and date footer updating every second.

Custom Theme: Styled using Bootstrap 5 combined with custom pastel pink styling.
